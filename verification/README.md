# Verification evidence

Machine-readable VR mappings live in `register.yaml`; bounded fixtures, scenarios, and generated
reports are kept under this directory. Test results are not considered passed until executable
evidence is recorded.

RAG quality gates and their current release-evidence boundary are documented in
`RAG-EVALUATION.md`. The example `rag-gold.example.json` demonstrates the versioned gold schema; it
is not by itself a release-scale benchmark.
